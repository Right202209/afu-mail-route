# 版本路线图：从 v1 到"像素 RPG 里的 3A"

> 写于 2026-10-12。v1.1 已完成；v2、v3 是规划，按"每一版都能独立发布、都能玩"来拆。

## 总原则

1. **每一版都能上线。** 每个版本结束时都是一个完整、可通关、可部署到 GitHub Pages 的游戏，不做"半成品大版本"。
2. **故事先行。** 地图和系统都为故事服务。新区域必须带着新的人和新的心结进来。
3. **数据驱动到底。** 剧情、地图、角色、任务都在 `data/` 里，引擎只做"怎么演"。这条从 v1 一直保留到 v3，它决定了后面能不能多人协作。
4. **狗不说话。** 不管世界多大，主角永远用动作回应世界。这是本作的"签名"。

## v2 · 扩大世界观：「雾海群岛」

### 世界设定
栖湾只是**雾海群岛**里的一座小镇。群岛之间靠一条老旧的**邮船航线**相连，岛与岛之间常年有雾——人们说，雾是没送到的话变的。邮差是群岛上最受尊重的职业之一：他们把话从一座岛带到另一座岛，让雾散开一点。

老周年轻时，是这条航线上最年轻的邮船水手。他后来留在栖湾，原因是一个他从未说出口的故事。

### 结构
| 元素 | 设计 |
|---|---|
| 区域 | 4 座岛，每座一个主题与一位"收信人群像"：**栖湾**（离别与重逢）、**盐田岛**（劳作与离乡）、**钟鸣城**（群岛首府，规则与人情）、**无名礁**（被遗忘的人） |
| 交通 | 邮船"信鸥号"，按航班表往返；错过就要等下一班——时间本身成为玩法 |
| 主线 | 阿福和小吴（见习邮差小雨同行）沿着老周年轻时的航线，把他珍藏的一叠**没寄出的信**送回各岛，拼出老周的过去 |
| 新系统 | **邮路规划**：每天的信件、航班和天气组合成一张路线图；**口碑**：每座岛对"栖湾邮局"的信任度，影响能接到哪些信；**雾**：没送到的信让雾变浓，送到后雾散，地图视野随之变化 |
| 伙伴 | 小吴（会读信、会写回信）、小雨（认路、能进小孩才进得去的地方）、煤球（会开锁，但总想偷看信） |
| 表现 | 章节制，每座岛一个章节（约 1–1.5 小时），总时长 6–8 小时 |
| 技术 | 继续零依赖；地图改用 Tiled 编辑器导出 JSON（保留代码画刷作为补充）；对话改用可视化编辑器（Twine/Ink 风格导入） |

### 里程碑
1. 世界观圣经（地理、历史、邮政制度、方言、节日）
2. 引擎：多区域加载、航班/时间系统、伙伴跟随
3. 盐田岛章节（可独立发布的 v2.0）
4. 钟鸣城、无名礁章节（v2.1、v2.2）
5. 老周的过去——终章（v2.3）

## v3 · 目标：像素 RPG 里的"3A"

"3A"在独立像素游戏里不是指预算，而是指**完成度**：美术、音乐、叙事、系统、打磨，每一项都做到同类作品的上游。对标作品：《去月球》（叙事）、《星露谷物语》（生活感与系统深度）、《八方旅人》（HD-2D 视觉）、《风来之国》（像素美术与氛围）、《Undertale》（选择的分量）。

### 要做到的事
| 维度 | v3 目标 |
|---|---|
| 美术 | 手绘像素：32×32 角色，每人 8 方向行走 + 表情动画；地图分层、视差、动态光照（HD-2D 风格：像素精灵 + 实时光影、景深） |
| 音乐 | 原创配乐 20–30 首，每座岛一个主题，昼夜/天气变奏；环境声（海浪、钟声、集市） |
| 叙事 | 主线 15–20 小时；每个有名字的 NPC 都有日程表和自己的故事；选择影响多章节后的世界 |
| 系统 | 邮路规划 + 生活模拟（天气、季节、节日）+ 轻度解谜；无战斗或极轻量冲突，保持本作温柔的调性 |
| 演出 | 关键剧情的过场动画、镜头运动、全屏插画 |
| 本地化 | 简中 / 繁中 / 英 / 日 |
| 平台 | Web 免费序章 + Steam / Switch 完整版 |

### 坦白说要多少资源
| 项目 | 估计 |
|---|---|
| 团队 | 核心 4–6 人：编剧/策划、程序、像素美术 ×2、作曲/音效；外包动画、本地化、测试 |
| 周期 | 2–3 年 |
| 技术 | 迁移到 **Godot 4**（开源、2D 能力强、可导出 Web/桌面/主机），把 v1/v2 的 `data/` 剧本格式写成导入器，剧情资产直接复用 |
| 资金路径 | v1/v2 免费网页版积累玩家 → 制作可玩 Demo → Steam 愿望单 / 众筹 / 独立游戏发行商 |

### v3 的第一步（现在就能开始）
1. **美术定调**：用 v1 的小镇做一张 32×32 手绘像素的"概念截图"，确定配色与光影。
2. **原型迁移**：在 Godot 4 里做一个只有邮局门口和一条街的垂直切片，读取现在的 `data/story-*.js` 剧本。
3. **配乐样本**：栖湾主题曲一首，白天/黄昏两个版本。
4. **写作**：完成 v2 世界观圣经，它就是 v3 的剧本地基。

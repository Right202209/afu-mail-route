# 部署指南：发布到 GitHub Pages

游戏是纯静态文件，没有构建步骤。下面三种方式任选一种。

## 方式 A：单独一个仓库（推荐）

1. 在 GitHub 新建仓库，比如 `afu-mail-route`。
2. 把整个 `afu-mail-route/` 文件夹的内容推上去（`index.html` 要在仓库根目录）：
   ```bash
   cd afu-mail-route
   git init && git add . && git commit -m "阿福的最后一班邮路"
   git branch -M main
   git remote add origin git@github.com:你的用户名/afu-mail-route.git
   git push -u origin main
   ```
3. 仓库 → **Settings → Pages** → Build and deployment 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。
4. 一两分钟后访问 `https://你的用户名.github.io/afu-mail-route/`。

仓库里已经带了 `.nojekyll`，GitHub 不会用 Jekyll 处理这些文件。

## 方式 B：用 GitHub Actions 部署

仓库里自带 `.github/workflows/pages.yml`。在 **Settings → Pages** 里把 Source 改成 **GitHub Actions**，之后每次推送到 `main` 都会自动发布。

## 方式 C：放进已有的个人站（比如 Jekyll 博客）

把整个文件夹复制到站点仓库的一个子目录，例如 `game/`：

```
你的站点仓库/
├── _config.yml
├── game/            ← 整个 afu-mail-route 的内容
│   ├── index.html
│   ├── css/ js/ data/ docs/
│   └── cover.png
```

访问 `https://你的站点/game/`。所有路径都是相对路径，放在任何子目录都能用。

Jekyll 站点需要注意：
- 文件夹名不要以下划线开头（Jekyll 会忽略 `_xxx` 目录）。
- 如果 `_config.yml` 里有 `exclude` 规则，确认没有排除 `game/`。
- 想在博客导航里加入口，链接到 `/game/` 即可；想嵌进文章里可以用：
  ```html
  <iframe src="/game/" style="width:100%;aspect-ratio:5/3;border:0" allow="fullscreen"></iframe>
  ```

## 本地试玩

- 直接双击 `index.html` 就能玩（脚本不是 ES module，不受 `file://` 限制）。
- 或者起一个本地服务器：
  ```bash
  python3 -m http.server 8000
  # 打开 http://localhost:8000
  ```

## 自定义域名

在仓库根目录加一个 `CNAME` 文件写上域名，再到域名服务商把 CNAME 记录指向 `你的用户名.github.io`。

## 分享卡片

`index.html` 里已经写了 `og:title`、`og:description`、`og:image`（`cover.png`）。部分平台要求 `og:image` 是绝对地址，部署后可以改成 `https://你的用户名.github.io/afu-mail-route/cover.png`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 打开是 404 | 等 1–2 分钟；确认 Pages 的分支和目录设置正确；确认 `index.html` 在所选目录的根部 |
| 画面空白 | 打开浏览器控制台看报错；常见原因是只上传了部分文件夹，`js/`、`data/` 都要上传 |
| 没有声音 | 浏览器要求先有一次点击/按键才能出声；也可能按了 P 静音 |
| 想清空进度 | 标题画面点"新的一天"；或浏览器控制台执行 `localStorage.clear()`（结局收集也会清掉） |
| 手机上按钮太小 | 横屏游玩；触屏按钮会随画面放大 |

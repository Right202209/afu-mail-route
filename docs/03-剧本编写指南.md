# 剧本编写指南：怎么改剧情、加角色、加结局

所有剧情都在 `data/` 目录里，是普通的 JavaScript 对象。改完刷新浏览器就能看到，不需要编译。

| 文件 | 放什么 |
|---|---|
| `data/world.js` | 小镇地图、建筑、道具、区域名 |
| `data/world-more.js` | 北林、室内地图、邮票 |
| `data/story-main.js` | 物品、信件、记忆、过场文字、**角色登场表**，邮局和道具的对话 |
| `data/story-town.js` | 五条故事线和居民的对话 |
| `data/story-endings.js` | 疗养院、终章、结局、尾声 |
| `data/story-v11.js` | v1.1 扩展；也示范了怎么用"补丁"方式往旧剧情里插入新分支 |

## 1. 对话节点

```js
lin_give: {
  who: 'lin',                       // 说话的人：角色 id；'none' 表示旁白（不显示头像）
  fx: 'd:lin;scene:letter_lin',     // 进入这个节点时执行的效果
  text: ['……这字，是阿青的。', '（她读了很久。）'],   // 多页，按空格翻页
  go: 'lin_give2',                  // 播完后跳到哪个节点；不写就结束对话
},
```

带选项：

```js
hai_first: {
  who: 'hai',
  text: ['……老周的狗。', '又是那小子的信吧。'],
  choices: [
    { t: '【把信放在他脚边，转身离开】', fx: 'd:hai;f:hai_left', go: 'hai_left' },
    { t: '【在他旁边趴下，等】', go: 'hai_wait1' },
    { t: '【叼出旧合影】', if: 'i:photo', go: 'xxx' },   // 有条件才出现的选项
    { t: '【走开】' },                                   // 没有 go：结束对话
  ],
},
```

按条件分支（第一个满足的生效）：

```js
hai_after: { who: 'hai', go: [
  { if: 'f:hai_wait', go: 'hai_after_w' },
  { go: 'hai_after_l' },          // 没有 if = 兜底
] },
```

没有 `text` 的节点是"路由节点"，会直接跳走，玩家看不到。

**顺序规则**：`fx` 在进入节点时立刻执行；其中的 `scene`（信纸/过场）会等本节点的文字播完再弹出；`m:`（记忆过场）和 `end`（结局）会等整段对话结束后再播放。

## 2. 条件语法

| 写法 | 含义 |
|---|---|
| `f:名字` | 旗标已设置 |
| `i:物品` | 邮包里有这个物品 |
| `m:记忆` | 已想起这段记忆 |
| `d:信` | 这封信已送达 |
| `p:信` | 这封信被偷看过 |
| `c:计数>=3` | 计数器比较，支持 `>= <= == > <` |
| `!` | 取反，如 `!f:clock_fixed` |
| `&` | 并且 |
| `\|` | 或者（优先级低于 `&`） |

内置计数器：`delivered`（已送达数）、`memories`（记忆数）、`peek`（偷看数）、`kindness`。你也可以随便起新名字，比如 `c:zc+1`，没用过的计数从 0 开始。

## 3. 效果语法（用 `;` 分隔）

| 写法 | 作用 |
|---|---|
| `f:名字` / `-f:名字` | 设置 / 清除旗标 |
| `i:物品` / `-i:物品` | 得到（会弹提示）/ 失去物品 |
| `d:信` | 送达这封信（计数+1、音效、提示） |
| `m:记忆` | 解锁记忆（对话结束后播放回忆过场） |
| `peek:信` | 标记为偷看过 |
| `c:名字+1` | 计数器加减 |
| `scene:过场id` | 弹出 `G.STORY.scenes` 里的过场 |
| `sfx:音效` | `blip select confirm bump bark item letter memory bell` |
| `toast:文字` | 屏幕上方弹一句提示 |
| `bell` | 钟楼敲钟（声音 + 画面波纹） |
| `end` | 对话结束后进入结局判定 |

## 4. 加一个新角色

在 `data/story-main.js` 的 `npcs` 里加一项：

```js
fisherboy: {
  name: '小海',
  look: { kid: true, hair: '#2b2118', style: 'short', shirt: '#4f74a8', pants: '#3a3a44' },
  at: [                                        // 站在哪儿：取第一个满足条件的
    { if: 'f:storm', x: 10, y: 33, dir: 'up' },
    { x: 14, y: 35, dir: 'down' },
  ],                                           // 都不满足 = 不出现
  talk: [                                      // 对话入口：取第一个满足条件的
    { if: 'd:hai', go: 'boy_after' },
    { go: 'boy_first' },
  ],
},
```

外观参数：`skin hair shirt pants shoes` 颜色；`style` 可选 `short long bun pigtails bald`；开关 `kid glasses blush cane`；颜色项 `apron hat scarf beard`。

然后在任一 story 文件里写 `boy_first`、`boy_after` 节点。坐标单位是格，可以打开 `docs/img/map.png` 对照（每格 16 像素）。注意别站在树、水、建筑上——测试脚本会检查。

## 5. 加一封信

在 `letters` 数组里加：

```js
{ id: 'boy', to: '渔具屋的小海', from: '……',
  hints: [ { if: 'd:boy', text: '已送达。' }, { text: '渔具屋在码头西边。' } ],
  peekToast: '信里说……' },
```

然后在 `scenes` 里加 `letter_boy` 作为信的内容，用 `d:boy` 送达。

> 主线目前写死"5 封送满才能拆最后一封"。如果信的数量改了，需要同步修改：`js/ui.js` 里的 `/5` 与 `>= 5`、`data/story-main.js` 里的 `c:delivered>=5`、`js/game.js` 里的 `dayTint`。

## 6. 加一段记忆 / 一个结局

- 记忆：在 `memories` 数组里加 `{ id, title, lines }`，用效果 `m:id` 解锁；终章 `zhou_hub` 里给它配一个动作选项。
- 结局：在 `G.STORY.endings` 里加一项 `{ id, title, sub, if, lines }`。**按顺序取第一个满足条件的**，所以条件越严格的放越前面。`lines` 里的元素可以是 `{ if, t }`，按条件显示。
- 尾声：`G.STORY.epilogues` 每组取第一个满足条件的段落。

## 7. 改地图

`data/world.js` 的 `build(m)` 用画刷画地图：

```js
m.fill('g');                 // 全部铺草
m.rect(x, y, w, h, 'w');     // 画矩形
m.set(x, y, 't');            // 单格
m.frame(x, y, w, h, 'e');    // 空心框（篱笆）
m.scatter(x, y, w, h, 'f', 0.12, 'h');   // 在花坡草地上随机撒野花
m.forest(0.09, 7);           // 随机种树（自动避开路、建筑、道具、角色）
```

地形字符：`g` 草地 `h` 花坡 `f` 野花 `p` 土路 `o` 石板 `s` 沙滩 `w` 水 `b` 桥 `k` 栈桥 `t` 树 `u` 灌木 `e` 篱笆 `r` 礁石。

建筑：`{ id, name, x, y, w, h, door, icon, roof, wall, awning, chimney }`，门在底边第 `door` 列。门前对话的节点名是 `door_建筑id`。

道具：`{ kind, x, y, solid, talk, if }`。`kind` 见 `js/tiles.js` 的 `prop()`：`mailbox sign board lamp bench crate barrel well boat easel crane gear photo dandelion gate stall bowl busstop flowerpot spark`。`talk` 以 `pick_` 开头的道具，踩上去就会自动触发。

## 8. 加一张新地图 / 室内（v1.1）

```js
G.MAPS.school_in = {
  id: 'school_in', name: '教室', indoor: true, w: 12, h: 8,
  palette: { wall: '#e0d8c0', wallD: '#c0b898', trim: '#5c3d22' },
  build(m) { m.fill('W'); m.rect(1, 2, 10, 5, 'F'); m.set(6, 7, 'M'); },
  warps: [{ x: 6, y: 7, to: 'town', tx: 9, ty: 13, dir: 'down' }],   // 踩门垫回小镇
  buildings: [], props: [], areas: [],
};
```

再给小镇里的建筑加 `enter: { to: 'school_in', x: 6, y: 6, dir: 'up' }`，需要条件才能进就加 `lock: '条件'`（锁着时显示 `door_建筑id_locked` 节点）。角色放进室内：`at` 里写 `map: 'school_in'`。室内字符：`W` 墙 `F` 木地板 `K` 石地板 `T` 瓷砖 `M` 门垫。

## 9. 自测清单

- 浏览器控制台没有"找不到对话节点 / 未知条件 / 未知效果"的警告。
- 每个新角色身边至少有一格能走到。
- 新的道具/物品，在需要它的地方之前一定拿得到（避免卡关）。
- 每个结局都至少走一遍。
